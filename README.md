Project Overview

This project is an Online Tutor Finder platform that allows users to search, register, and find tutors based on their preferences. The platform includes various functionalities such as tutor profile management, course posting, and user authentication.

Key Features:

User Authentication: Users can log in, register, and log out. The system supports user authentication to ensure secure access to features.

Tutor Profiles: Tutors can create and manage their profiles with information about the courses they offer. Tutors can also update their details through dedicated pages.

Course Posting: Tutors can post available courses, and users can view the posted courses, filtered by subject and other criteria.

Search Functionality: Users can search for tutors based on various parameters such as location, subject, and ratings.

Notifications: The system supports notifications, likely for actions like course approvals or updates.

Admin Functions: Admins can approve tutors, delete posts, and manage user data.

Files and Directories:

PHP Files: Several PHP files (e.g., index.php, registration.php, login.php) handle different parts of the application, including user registration, login, profile management, and course posting.

CSS and JS: The project includes styles (css) and scripts (js) for the front-end design and interactivity.

Images: The image directory contains images likely used for the platform's UI.

Database: The main_db.sql file likely contains the database schema to set up the back-end database.

Includes: The inc folder likely holds reusable PHP files such as header/footer templates or functions used across different pages.

Usage:

This project can be used to build an online tutor marketplace where students can find tutors based on specific criteria like location, subject, and availability. It provides both user and admin functionality to manage profiles, posts, and tutor approvals.
